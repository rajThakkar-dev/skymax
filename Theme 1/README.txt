SKYMAX SOLUTIONS — DIGITAL FORWARD (DESIGN 3)
================================================

A complete, responsive, static multipage website prototype based on the selected Digital Forward concept.

PREVIEW
1. Open index.html in a browser.
2. Use the navigation to browse pages.
3. Works as a standalone set of files — no build process, fonts or external dependencies.

PAGES

- workday.html — Workday-focused services
- services.html — Enterprise technology services
- about.html — Company profile
- careers.html — Talent / careers

- privacy.html — Preview-only privacy notice

ASSETS
- assets/styles.css — Global design system and responsive styles
- assets/site.js — Mobile navigation and safe demonstration forms
- assets/skymax-logo.svg — Vector logo
- assets/favicon.svg — Favicon
